## 2025-03-01 - Decoupling High-Frequency Game Loop Updates
**Learning:** High-frequency state updates (60fps requestAnimationFrame) of the game multiplier inside the custom `useGameSocket` hook triggers huge rendering overhead across the entire React component tree (under `Home.tsx`). This causes heavy CPU usage and lag.
**Action:** Decouple `multiplier` and `elapsedMs` from the declarative React state. Use React `useRef`s to store the high-frequency values (`flyStartRef` and `elapsedRef`), and update high-frequency elements (like the central multiplier text, rocket position, and real-time cashout value) directly on the DOM in lightweight animation loops. Use `useLayoutEffect` to re-sync manual DOM updates after React's discrete state-driven re-renders (like phase transitions) to prevent rendering flickering or snapping.
