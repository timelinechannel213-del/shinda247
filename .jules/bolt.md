## 2025-03-03 - Decouple High-Frequency UI Updates
**Learning:** High-frequency React state updates (e.g., 60fps tickers) cause substantial virtual DOM reconciliation overhead across the entire component tree, leading to layout thrashing, lagging, and battery drain. Decoupling high-frequency visual states from React state using refs and direct DOM manipulation via requestAnimationFrame is an extremely effective optimization. However, to prevent 'flickering' or resetting to default state when React eventually does a declarative re-render (e.g., due to phase changes or other state updates), we must use the `useLayoutEffect` hook to immediately synchronize the manual DOM updates (multiplier, position, rotation, etc.) using the single source of truth reference (`flyStartRef`).
**Action:** Always coordinate high-frequency animation loops via parent components (like `Home.tsx`), pass synchronized `flyStartRef` refs to children, and utilize `useLayoutEffect` to safely re-apply manual styles/content immediately upon any component re-render.
