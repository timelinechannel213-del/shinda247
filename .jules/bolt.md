## 2026-06-05 - Decoupled high-frequency React updates in Rocket Crash Game
**Learning:** High-frequency rendering loops (such as requestAnimationFrame running at 60 FPS) calling React state setters (like `setGameState`) cause massive, unnecessary component tree re-renders and virtual DOM diffing. Decoupling high-frequency visual elements (such as the canvas curve, rocket position/rotation/flame, and real-time multiplier text) from React state, and using direct DOM manipulation via refs, completely eliminates this bottleneck. Additionally, utilizing `useLayoutEffect` to synchronize manual DOM states immediately after any reactive state updates is critical to prevent visual flickering or snapping to stale values.
**Action:** When working with continuous animative values, always decouple them from React state. Directly update DOM elements in the RAF loop using refs, and use `useLayoutEffect` to synchronize visual styles after discrete React state changes.
