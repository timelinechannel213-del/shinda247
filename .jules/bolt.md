## 2025-02-12 - Decoupled High-Frequency Rocket Crash Game Updates
**Learning:** High-frequency state updates (60fps) within a central hook like `useGameSocket` trigger complete React render loops across the entire application tree on every frame. Moving state updates out of the animation frame loops and mutating critical DOM elements (the canvas rocket coordinate position, rotation, multiplier text, and cash-out button value) directly via stable `useRef` handles eliminates the render cycle overhead during active flights, improving frames-per-second consistency and significantly reducing CPU consumption.
**Action:** Always decouple animation ticks and real-time socket calculations from React states when handling high-frequency animations (60fps), and synchronize DOM values immediately post-render using `useLayoutEffect` to avoid visual flicker or layout snapping.
