## 2026-07-07 - Decoupling High-Frequency Updates from React State
**Learning:** In real-time applications like a crash game, updating React state at 60fps (e.g., via `requestAnimationFrame` in a hook) causes massive re-render overhead across the entire component tree. This leads to high CPU usage, UI lag, and potential 'snapping' or 'flickering' as React tries to keep up with the declarative state vs. the imperative DOM.
**Action:** Use `useRef` for high-frequency values (like time elapsed or multiplier) and update DOM elements directly via `element.style` or `element.textContent` in the RAF loop. Coordinate these updates by passing refs from a central hook (`useGameSocket`) to consumer components (`GameCanvas`, `GameControls`). Always use `useLayoutEffect` to re-apply manual updates after any React re-render to prevent visual state resetting.
